# Funngro Website Content Enhancement

## Project Overview

This project focuses on improving the content, readability, SEO, accessibility, and overall presentation of the Funngro website.

The website is designed to help teens and students discover real-world projects, develop practical skills, gain experience, and explore future opportunities.

## Objectives

* Improve website content and readability
* Make the website more SEO-friendly
* Improve page titles and meta descriptions
* Use relevant keywords naturally
* Improve mobile navigation accessibility
* Create clear calls to action
* Improve the overall user experience
* Maintain a clean and responsive design

## Pages Included

### 1. Home Page

**File:** `index.html`

The home page introduces Funngro and highlights:

* Real-world projects
* Practical skill development
* Experience building
* Project opportunities
* Benefits for young talent

### 2. Teens Page

**File:** `teen.html`

The teens page focuses on:

* Opportunities for teens and students
* Practical learning
* Portfolio building
* Skill development
* Project experience
* Step-by-step project journey

## SEO Improvements

The following SEO improvements were implemented:

* Optimized page titles
* Improved meta descriptions
* Added relevant keywords
* Added `robots` metadata
* Added Open Graph metadata
* Improved heading structure
* Improved search-friendly website content

### Example Keywords

* Teen freelancing
* Student projects
* Real-world projects
* Student experience
* Skill development
* Practical learning
* Project-based experience

## Accessibility Improvements

The mobile navigation was improved with:

* Accessible menu button
* `aria-label`
* `aria-expanded`
* Responsive navigation
* Navigation automatically closes after selecting a link

## Responsive Design

The website has been designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile phones
